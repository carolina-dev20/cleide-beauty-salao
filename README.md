# Cleide Beauty Salão | Business Website

A modern, responsive business website developed for **Cleide Beauty Salão**, a beauty salon located in Guarulhos, São Paulo, Brazil.

This project was designed to strengthen the salon's online presence, showcase its services, improve local search visibility, and provide customers with a seamless appointment booking experience.

## Tech Stack

- **Next.js** — React framework for modern web development.
- **React** — Component-based user interface development.
- **TypeScript** — Type-safe and maintainable code.
- **Tailwind CSS** — Responsive styling and modern UI design.
- **Google Analytics 4** — Website analytics with user consent.

## Key Features

- Fully responsive design across desktop, tablet, and mobile devices.
- Modern user interface with smooth animations and transitions.
- Service presentation and portfolio gallery.
- Appointment request form integrated with WhatsApp.
- Google Maps integration for business location.
- Local SEO optimization with metadata and structured data.
- XML sitemap and robots.txt configuration.
- Privacy Policy and cookie consent management.
- Google Analytics 4 integration.

## Project Goals

The main goal was to develop a professional digital solution for a local business, combining modern Front-end technologies with usability, performance, and search engine optimization.

The project demonstrates practical experience in building and deploying a real-world commercial website, from UI development to production deployment.

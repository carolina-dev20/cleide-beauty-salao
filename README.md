# Cleide Beauty Salão — Beauty Salon Website

A modern, responsive beauty salon website built with **Next.js, React, TypeScript, and Tailwind CSS**, designed to strengthen the salon's digital presence and simplify appointment requests.

🌐 **Live Demo:** https://cleide-beauty-salao.vercel.app/

## About the Project

Cleide Beauty Salão is a real-world web development project created for a beauty salon in Guarulhos, São Paulo, Brazil.

The website combines an elegant user interface with practical features to improve the customer experience, showcase beauty services, and encourage appointment requests.

## Key Features

- Responsive design for desktop and mobile devices
- Modern and minimalist user interface
- Beauty services showcase
- Appointment request form integrated with WhatsApp
- Form validation using React Hook Form and Zod
- Direct links to WhatsApp, Instagram, and Google Maps
- SEO-focused page structure
- Production deployment with Vercel

## Appointment Request Workflow

1. The customer selects a beauty service.
2. The customer enters their name, preferred date, and time.
3. The form validates the submitted information.
4. WhatsApp opens with a pre-filled appointment request.
5. The salon confirms availability directly with the customer.

This solution provides a straightforward appointment-request experience without requiring a backend booking system.

## Running Locally

Clone the repository:

```bash
git clone https://github.com/carolina-dev20/cleide-beauty-salao.git
cd cleide-beauty-salao
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
